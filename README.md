# Crop Price Prediction and Profit Analysis System

## Overview

The Crop Price Prediction and Profit Analysis System is a Flask-based web application designed to help farmers, agricultural analysts, and administrators predict crop prices, manage users, and analyze crop profitability. The system provides secure user authentication, crop price prediction capabilities, review management, and administrative monitoring features.

## Features

### User Features
- User Registration and Login
- Secure Password Hashing
- Crop Price Prediction Interface
- Submit Reviews and Ratings
- View Prediction Results
- User Session Management

### Admin Features
- Admin Login Authentication
- Review Monitoring Dashboard
- User Management Support
- System Administration Panel

### Machine Learning Features
- Crop Price Prediction Model
- Data Preprocessing using Scaler
- Label Encoding for Crop Types
- Profit Analysis Database

### Database Features
- User Management Database
- Admin Management Database
- Crop Profit Database
- Review Storage System
